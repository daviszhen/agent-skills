# criteria-audit

An agent skill for auditing a product / direction / idea with the three hard criteria and three axes (including the AI test).

## Install

Copy the `criteria-audit/` folder into your agent's skills directory, e.g.:

- Claude Code: `~/.claude/skills/criteria-audit/`
- Other agents: wherever `SKILL.md` files are discovered.

The skill triggers on questions like "is this worth doing", "should I build this", or "帮我判断这个方向".

## Files

- `SKILL.md` — the skill instructions.
- `README.md` — this file.
